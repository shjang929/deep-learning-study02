## 핵심 정리

- **합성곱**: 3×3 필터 하나를 이미지 전체에 재사용한다. 위치가 달라도 같은 패턴을 찾고, 파라미터가 이미지 크기와 무관하게 작다.
- **풀링**: 2×2마다 최댓값만 남겨 크기를 절반으로 줄인다. 층이 쌓일수록 더 넓은 영역을 본다.
- **`view(-1, N)`**: 합성곱 출력을 `nn.Linear`에 넣기 위해 한 줄로 펼친다. `N`은 `fc1`의 입력 크기와 같아야 한다.
- **GPU**: 모델과 데이터를 **둘 다** `.to(device)`로 옮겨야 한다.
- **검증**: 반드시 학습에 쓰지 않은 데이터(`train=False`)로 잰다. 드롭아웃·배치 정규화가 있으면 `model.eval()`로 평가한다.

## 모델 비교 결과

같은 조건(시드 0, SGD, 100 에포크)으로 학습한 결과다.

| 모델 | 바꾼 점 | 파라미터 | train | val |
| --- | --- | --- | --- | --- |
| baseline | 합성곱 2층 | 18,090 | 0.911 | **0.888** |
| width | 채널 16 → 32 | 38,386 | 0.901 | 0.863 |
| l2 reg | + L2 정규화 | 38,386 | 0.888 | 0.853 |
| dropout | + Dropout2d(0.4) | 38,386 | 0.889 | 0.871 |
| batchnorm | + BatchNorm2d | 38,482 | 0.980 | 0.877 |
| depth | 합성곱 3층 | 16,130 | 0.883 | 0.877 |
| res | + 스킵 연결 | 16,130 | 0.895 | 0.877 |
| res deep | ResBlock 10개 | 159,330 | 0.701 | 0.699 |

![여덟 모델의 train/val 정확도 비교](images/model-comparison.png)

- 검증 정확도는 대부분 0.85~0.89로 비슷했고, 차이는 train과의 간격에서 났다.
- batchnorm은 간격이 10.3%p로 가장 컸다.
- res deep은 학습 손실이 0.0036까지 떨어졌지만, 평가 모드에서 배치 정규화 통계가 맞지 않아 처음엔 0.50이 나왔다. 통계를 다시 계산해 0.70까지 회복했다.
